# The name: Tangent → Anabranch (decision)

Decided 25 July 2026, before the first public post and before the skeleton gate.
This closes the open risk item the spec recorded as "The name."

## The decision

The artifact is **Anabranch**, live at `anabranch.vercel.app` — the subdomain was
confirmed free and claimed the same day, at the skeleton gate. The repo is
`github.com/alexstrasman/anabranch`.

An anabranch is a river channel that diverges from the main stem and rejoins it
downstream. It names the whole idea rather than the shipped subset: v1 diverges
only, and rejoining — merging threads — is parked in `LATER.md` as known future
work.

No domain was purchased and no social handle was created. Posts go out from
Alex's own account. Both of those are deliberate and are argued below.

## Why the rename happened

The spec's risk item asked for a check, not a purchase: *"check handle and
domain availability before the first public post, and rename cheaply then if
needed, not later."*

The check found a direct collision. **[itsPreto/tangent](https://github.com/itsPreto/tangent)**
— "Excalidraw meets ComfyUI for LLMs," 318 stars, 28 forks, created November
2024, last commit August 2025 — is a canvas for branching AI conversations. Same
name, same concept. There is also a live Chrome extension, "Tangent – Threaded
Chat for ChatGPT & Claude," in the same space, and an unrelated `tangent.ai`.

None of that is competitive risk. The spec already settles competition:
branching-chat tools existing is "irrelevant to an artifact whose job is proof
and point of view." The problem is narrower and real — **legibility**. A reader
who hears "Tangent" and searches it finds a 2024 repo doing the same thing, not
Alex. For an artifact whose entire output is build-in-public content, search
legibility *is* the asset.

## The test applied

Collision, not acquisition. The question was never "can I own this name
everywhere," it was "will using this name make my posts confusing or invisible."
That framing is what makes a dormant repo survivable and an active trademark in
the buyer's own category fatal.

Secondary constraints: typo-proof when heard once and typed into a browser;
sayable aloud on a screen recording; a free `.vercel.app` subdomain, since the
scope contract asks only for "a web app with a live URL" and buying a domain is
the small step that quietly reframes an artifact as a startup.

## Candidates checked

Thirty-one names across four lanes. All `.vercel.app` subdomains probed
25 July 2026; GitHub star counts from the GitHub search API.

### Lane A — describes the interaction

| Name | Result |
|---|---|
| Tangent | Collides with a 318★ branching-AI-chat canvas of the same name — the reason for this exercise |
| Bough | Subdomain serves **"Bough — Branching writing canvas."** Someone already made this exact move |
| Offshoot, Sidenote, Sidetrack, Aside, Segue, Spur, Byway | Subdomains all taken by live products |
| Sprig, Treeline, Branchline, Tine, Coppice, Warren | Subdomains taken |
| Thicket | Subdomain free, but the word connotes the impenetrable tangle the tool *solves*, not the solution |
| Frond, Rill, Stolon, Tiller | Subdomains free; none of them say "branching" to a reader |

**Finding: this lane is exhausted.** Every tool built on this idea reaches for
the same vocabulary — branch, tree, thread, fork, tangent — so it is where the
collisions concentrate and where they will keep appearing.

### Lane B — Inception-derived (nesting and layers)

Proposed on the intuition that nested dream levels mirror how branches inherit
context. Half right: inheritance is real (context assembly *is* the ancestor
chain), but Inception is **linear descent** — one dream inside one dream — while
this tool is **lateral divergence**, a tree with siblings compared side by side.
The film has no concept of two branches from one point, which is the product.

| Name | Result |
|---|---|
| Penrose | **Dead.** [Penrose](https://penrose.github.io/) is a CMU diagramming tool — visual, design-adjacent, the same neighbourhood |
| Eames | Subdomain taken; borrowing Charles & Ray Eames for one's own design artifact reads presumptuous |
| Totem, Kick, Paradox, Limbo, Dreamscape, Spinner, Cobb, Somnus, Mombasa, Arthur, Saito, Fischer | Taken and/or overloaded generic words; "Limbo" also connotes being stuck |
| Ariadne | Free subdomain, best meaning found, rejected — see below |

Useful side effect: because the lane's vocabulary is nesting rather than
branching, it sits *outside* the collision zone that killed lane A.

### Lane C — abstract real words

| Name | Result |

An active trademark in the buyer's own category is the one genuinely bad outcome here |
| Braid | **Dead — worst trifecta for this audience:** [Braid design system](https://github.com/seek-oss/braid-design-system) (1,571★), [braidchat/braid](https://github.com/braidchat/braid) — *"team-chat app with a novel UI"* (937★), and Jonathan Blow's 2008 game, which every designer knows |
| Scion | GoogleCloudPlatform/scion (1,643★) and [SCION Internet Architecture](https://github.com/scionproto/scion) (550★). Compromised |

### Lane D — deliberately plain

Not pursued. `tangent-canvas`, `tangentapp` and `trytangent` were confirmed free,
which mattered — see the correction below.

## Why Ariadne was rejected

Ariadne had the best meaning of anything found. In *Inception* she is the
architect who designs the dream space; in myth she gives Theseus the thread to
navigate the Labyrinth. And **the word "clue" descends from "clew," a ball of
thread, taking its modern meaning directly from that myth** — the etymological
origin of following a thread through a confusing space. A designer, a thread,
and a navigable maze in one word. The subdomain was free.

Rejected on the accumulation of four costs:

- [mirumee/ariadne](https://github.com/mirumee/ariadne) — 2,343★ Python GraphQL
  library, active
- zesterer/ariadne — 2,161★ Rust diagnostics crate
- [Ariadne Labs](https://www.ariadnelabs.org/about-us/) (Harvard/Brigham),
  Ariadne Maps GmbH, ARIADNE EU archaeology infrastructure
- Four syllables, reliably mispronounced, phonetically muddled with *Ariane*,
  unspellable on first hearing

Two 2,000★ active developer libraries is a **worse** collision than Tangent's
single dormant repo. Rich meaning, but it failed the one test it had to pass.

## How the exercise nearly ended, and what flipped it

After three lanes, the honest scoreboard had **Tangent winning**. Its collision
was one dormant repo; every alternative surfaced something worse. A correction
also removed the second reason to rename: `tangent-canvas.vercel.app`,
`tangentcanvas`, `tangentapp` and `trytangent` were all free, so the subdomain
was never actually blocked. The earlier framing that the clean URL was "gone"
overstated the case.

Two things then flipped it to Anabranch:

1. **Merging is the eventual intent.** The objection to Anabranch was that it
   promises rejoining, which v1 does not do. Once merging was confirmed as
   genuinely wanted, that objection inverted: the name describes the finished
   idea rather than the shipped subset, which is normal and good practice.
2. **Search legibility, which is the actual asset.** "Tangent" returns a dormant
   look-alike repo, three unrelated products and a maths concept. "Anabranch"
   returns nothing in this space at all. For an artifact whose output is
   build-in-public content, being uniquely findable beats being instantly
   legible.

A third, smaller: the definition is a launch post. *"An anabranch is a river
channel that splits off from the main stem and rejoins it downstream — that's
what this does with a conversation."* The "nobody knows the word" objection
inverts too; a name you get to define is content, not friction.

## Costs accepted

- **No instant legibility.** The word must be taught. Mitigated by the fact that
  teaching it is a post.
- **Three syllables**, though phonetically unambiguous (AN-uh-branch) and it
  spells the way it sounds.
- **Still contains "branch,"** so it has not fully escaped the crowded semantic
  lane — but the compound is unique, which is what matters for collision.
- **The name anticipates a feature that may never ship.** Accepted knowingly;
  see `LATER.md`.
- **The X handle is unverified and probably unavailable.** Costs nothing, because
  no handle is being created.

## Explicitly not done

- **No domain purchased.** A Vercel subdomain satisfies the scope contract's "a
  web app with a live URL." Buying a domain is the small step that reframes an
  artifact as a startup, which the spec guards against.
- **No `@anabranch` social handle.** It would split the audience being built —
  the follower should end up following Alex, not a tool — reframe an artifact as
  a product with its own brand presence, and create an account that needs feeding
  after the six themes are done. X's Platform Manipulation Policy also prohibits
  using a second account to boost the first, which is the pattern anyone would
  naively adopt.
- **No X "business account."** That means Verified Organizations: $200–1,000 per
  month plus an application. Irrelevant at this scale.

## What changed in the repo

- `docs/spec.md` — name throughout; the "The name" risk item closed with the
  finding. The ordinary English phrase "going off on a tangent" was deliberately
  left intact.
- `LATER.md` — name throughout, plus merging/rejoining added with its DAG cost.
- `docs/superpowers/plans/2026-07-24-tangent.md` → `...-anabranch.md`, name and
  identifiers throughout: `package.json` name, `<title>`, the localStorage keys
  (`anabranch:canvas:v1`, `anabranch:apiKey`), the export filename
  (`anabranch-canvas.json`), the OG title, the README template. Task 12 gained an
  explicit instruction to name the Vercel project `anabranch`.
`README.md` is **not** part of this branch. Task 12 creates it alongside the code
in the Phase A branch, which is where it belongs; duplicating it here would only
produce a merge conflict.

The build workspace was told to rename the code identifiers before Task 12,
because three things harden at the deploy gate: the **localStorage keys**
(changing the prefix after real use silently orphans every saved canvas), the
**Vercel project name** (which *is* the public URL, and renaming it later breaks
posted links), and the cosmetic title strings.

## Fallback

If a real collision emerges mid-build, do not re-run this exercise. Lane A is
exhausted, and Strata, Braid, Penrose, Scion and Ariadne are all documented dead
above. The next candidates with free subdomains and no meaningful collision were
**Thicket**, **Frond**, **Rill**, **Stolon** and **Tiller** — all weaker, all
available.
